# Percipio C++ 服务 - 快速开始

**最后更新**: 2026年5月14日

## 快速命令

### 1. Windows x86_64 编译

```bash
cd C:\Users\zzulr\Desktop\LBGM461

# 方式 A: 使用 VS 生成器（当前环境已验证通过）
cmake -S . -B out/build/vs2022-x64 -G "Visual Studio 17 2022" -A x64 -DLBGM461_ENABLE_SYNTHETIC_CAMERA=ON
cmake --build out/build/vs2022-x64 --config Debug --target camera_service

# 方式 B: 使用 CMake 预设（需要先安装 Ninja）
cmake --preset windows-debug
cmake --build --preset windows-debug

# 查看输出
dir out\build\vs2022-x64\Debug\camera_service.exe
```

**预期结果**:
```
PercipioCamera.cpp - 编译成功
camera_service.exe - 生成成功（大约 300KB）
```

### 3. C# 客户端测试

先确认你的构建启用了 gRPC。若当前输出包含 "gRPC dependencies are not enabled in this build"，则本节暂时不可用。

启用 gRPC 后，在现有的 C# 控制程序中添加测试代码：

```csharp
// 假设 C++ 服务运行在 127.0.0.1:5111
var channel = new Channel("127.0.0.1", 5111, ChannelCredentials.Insecure);
var client = new ImageService.ImageServiceClient(channel);

var request = new ProtoYoloRequest {
    ModelName = "test",
    PathSuffix = "test_frame_001",
    IsOnlyImages = true
};

var response = client.GetYoloResult(request);

Console.WriteLine($"Status: {response.Status}");
Console.WriteLine($"Path: {response.Path}");
Console.WriteLine($"Ticks: {response.Ticks}");

// 读取共享内存
if (response.Status == 0) {
    var data = ReadSharedMemory(response.Path);
    Console.WriteLine($"Shared memory size: {data.Length} bytes");
}
```

## 故障排除

### 编译失败 - "cannot find vcamera/camera.h"

**原因**: 头文件未复制  
**解决**:
```bash
# 确认头文件存在
dir C:\Users\zzulr\Desktop\LBGM461\include\vcamera\
# 应显示 11 个 .h 文件
```

### 运行失败 - "gRPC dependencies not enabled in this build"

**原因**: 这是正常警告，protobuf/gRPC 未找到  
**影响**: 无 gRPC 网络服务，但 synthetic 模式仍可运行  
**解决**: 无需操作，使用 synthetic 模式进行测试

### 无法连接摄像头 - "No Percipio camera device found"

**原因**: 设备未连接或驱动未安装  
**解决**:
```bash
# 查看可用设备列表
# 运行 VcameraSDK 提供的 ListDevices 示例
# 或从设备管理器检查 USB 设备

# 临时解决: 使用 synthetic 模式
.\camera_service.exe --synthetic
```

### 共享内存文件损坏

**原因**: 帧数据转换有误  
**诊断**:
```csharp
// 检查返回的路径和大小
Console.WriteLine($"Memory path: {response.Path}");

// 验证 ticks 单调递增
var prev_ticks = 0L;
for (int i = 0; i < 10; i++) {
    var resp = client.GetYoloResult(request);
    Console.WriteLine($"Ticks: {resp.Ticks} (delta: {resp.Ticks - prev_ticks}ms)");
    prev_ticks = resp.Ticks;
}
```

## 编译选项

### 仅 Synthetic 模式（默认）

```bash
cmake -B out/build/vs2022-x64 \
      -DLBGM461_ENABLE_SYNTHETIC_CAMERA=ON \
      -DLBGM461_ENABLE_PERCIPIO_SDK=OFF
```

### 启用 Percipio SDK（如有库可用）

```bash
cmake -B out/build/vs2022-x64 \
      -DLBGM461_ENABLE_SYNTHETIC_CAMERA=ON \
      -DLBGM461_ENABLE_PERCIPIO_SDK=ON \
      -DLBGM461_PERCIPIO_SDK_ROOT=C:\Users\zzulr\Desktop\GM461\VcameraSDK-26.1.5
```

### 同时启用 gRPC

```bash
# 需要先安装 protobuf 和 gRPC 开发包
# 然后使用标准 CMake 配置

cmake -B out/build/vs2022-x64 \
      -DLBGM461_ENABLE_GRPC=ON \
      -DLBGM461_ENABLE_PERCIPIO_SDK=ON
```
