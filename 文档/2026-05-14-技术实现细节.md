## 1. 架构概览

### 1.1 整体架构

```
┌─────────────────────────────────────────────────────────┐
│                   C# Control Program                    │
│           (127.0.0.1:5111 gRPC Client)                  │
└────────────────────┬────────────────────────────────────┘
                     │ gRPC GetYoloResult
                     ▼
┌─────────────────────────────────────────────────────────┐
│          camera_service (C++ Linux/Windows)             │
│                                                         │
│  ┌──────────────────────────────────────────────────┐  │
│  │  GrpcServer (Port 5111)                          │  │
│  │  └─ ImageService::GetYoloResult()                │  │
│  └─────────────┬──────────────────────────────────┬─┘  │
│               │                                  │     │
│               ▼                                  │     │
│  ┌──────────────────────────┐   ┌────────────────▼──┐ │
│  │  CameraService           │   │ SharedFrameWriter │ │
│  │  ├─ GetYoloResult()      │   │ ├─ Write()        │ │
│  │  ├─ NextTicks()          │   │ └─ /dev/shm/*     │ │
│  │  └─ MemoryShare path     │   └──────────────────┘ │
│  └────────────┬─────────────┘                         │
│               │                                       │
│               ▼                                       │
│  ┌──────────────────────────┐                        │
│  │  PercipioCamera          │                        │
│  │  ├─ Init()               │                        │
│  │  ├─ Connect()            │                        │
│  │  ├─ Start()              │                        │
│  │  ├─ Grab()               │  (Pimpl隐藏SDK)       │
│  │  └─ Stop()               │                        │
│  └────────────┬─────────────┘                        │
│               │                                       │
│               ├──────────────┬──────────────┐        │
│               ▼              ▼              ▼        │
│     ┌──────────────┐ ┌──────────────┐ ┌──────────┐  │
│     │ Synthetic    │ │ Percipio SDK │ │ Callback │  │
│     │ FrameGen     │ │ (Real HW)    │ │ Handler  │  │
│     │ (Test Mode)  │ │              │ │ (Async)  │  │
│     └──────────────┘ └──────────────┘ └──────────┘  │
│                                                      │
└──────────────────────────────────────────────────────┘
             ▲
             │ USB / Network
             ▼
    ┌─────────────────┐
    │ Percipio Camera │
    │ (GM461 etc)     │
    └─────────────────┘
```

### 1.2 数据流

```
1. C# 调用 GetYoloResult(request)
   ↓
2. gRPC Server 转发给 CameraService::GetYoloResult()
   ↓
3. CameraService 从 PercipioCamera::Grab() 获取最新帧
   ↓
4. PercipioCamera.Impl 通过以下任一方式获取帧：
   a) Synthetic 模式: GenerateSyntheticFrame() 生成虚拟帧
   b) SDK 模式: OnFrameSetCallback() 接收 Percipio 真实帧
   ↓
5. CameraService 更新 Ticks（单调递增）
   ↓
6. SharedFrameWriter 序列化帧数据到 /dev/shm/ImageMemoryShareData_<suffix>
   ↓
7. gRPC 返回 (Status=0, Path, Ticks)
   ↓
8. C# 从共享内存读取帧数据并反序列化
```

## 2. 核心组件详解

### 2.1 PercipioCamera::Impl (Pimpl Implementation)

**设计模式**: Pimpl (Pointer to Implementation)

**优点**:
- ✅ SDK 头文件依赖隐藏在 .cpp 中
- ✅ 无 SDK 时仍能编译（条件编译）
- ✅ 公有接口不变，向后兼容

**关键成员**:

```cpp
class PercipioCamera::Impl {
    ServiceConfig config_;          // 配置参数
    std::mutex mutex_;              // 线程同步
    std::condition_variable cv_;    // 帧就绪信号
    std::thread worker_;            // 帧处理线程
    
    bool initialized_, connected_;  // 状态标志
    bool running_, stop_requested_; // 生命周期控制
    
    FrameSnapshot latest_frame_;    // 最新帧缓存
    std::int64_t latest_ticks_;     // 最新 ticks
    
#ifdef LBGM461_ENABLE_PERCIPIO_SDK
    vcamera::Camera camera_;        // SDK 摄像头对象
#endif
};
```

### 2.2 帧回调处理 (OnFrameSetCallback)

**执行上下文**: SDK 内部线程（异步）

**数据转换流程**:

```cpp
SDK FrameSet {
    Image depth_img (YPbPr or DEPTH16)
    Image color_img (BGR or BAYER)
    ...
}
↓ (OnFrameSetCallback)
↓ 提取 width, height, data 指针
↓ 复制到 std::vector<uint8_t>
↓ 填充 FrameSnapshot 结构体
↓ 锁定 mutex，更新 latest_frame_
↓ 通知 condition_variable
↓ 返回 (SDK 继续采集)
```

**线程安全**:
- 使用 `std::lock_guard<std::mutex>` 保护共享数据
- `latest_ticks_` 用于检测新帧（避免重复）
- condition_variable 用于 Grab() 等待

### 2.3 Synthetic Frame Generator

**用途**: 在无 SDK 或测试时生成虚拟帧

**实现**:

```cpp
FrameSnapshot GenerateSyntheticFrame(int64_t ticks) {
    // 生成 BGR 彩色图
    for (x, y in frame) {
        B = (x + tick_low) % 256
        G = (y + tick_low) % 256
        R = ((x + y) + tick_low) % 256
    }
    
    // 生成 Depth 图 (uint16)
    for (x, y in frame) {
        depth[x,y] = 500 + ((x + y) % 1000)  // 模拟远近深度
    }
    
    // 返回完整的 FrameSnapshot
    return frame;
}
```

**特点**:
- ✅ 确定性输出（便于单元测试）
- ✅ 模拟真实摄像头数据格式
- ✅ 低 CPU 占用（O(width*height)）

## 3. SDK 集成关键接口

### 3.1 CameraUtils

```cpp
namespace vcamera {
    class CameraUtils {
        static CameraApiStatus Init(bool direct_mode);
        static std::vector<CameraInfo> DiscoverCameras();
    };
}
```

**说明**:
- `Init(true)`: 直接模式（无需 RPC 服务）
- `DiscoverCameras()`: 返回可用设备列表

### 3.2 CameraFactory

```cpp
namespace vcamera {
    class CameraFactory {
        static Camera GetCamera(std::string sn, std::string ip);
    };
}
```

**说明**:
- 按 SN 或 IP 获取摄像头对象
- 两个参数其一为空时以另一个搜索

### 3.3 Camera

```cpp
namespace vcamera {
    class Camera {
        CameraApiStatus Connect();

        CameraApiStatus StopCapture();
        CameraApiStatus Disconnect();
        
        void SetSensorEnabled(std::string sensor, bool enable);
        void SetMapDepthToTextureEnabled(bool enable);
        void RegisterFrameSetCallback(FrameSetCallback cb);
    };
}
```

**回调签名**:
```cpp
using FrameSetCallback = std::function<void(const FrameSet&)>;
```

### 3.4 FrameSet & Image

## 5. 错误处理策略

### 5.1 CameraApiStatus 检查

```cpp
CameraApiStatus status = camera.Connect();
if (!status.IsSuccess()) {
    SetError(std::string("Connect failed: ") + status.message());
    return false;
}
```

**说明**:
- `status.IsSuccess()`: 返回 bool
- `status.message()`: 返回错误描述字符串

### 5.2 设备不可用降级

```cpp
bool Connect() {
    if (!config_.synthetic_camera) {
        try {
            auto list = CameraUtils::DiscoverCameras();
            if (list.empty()) {
                // 降级到 synthetic
                config_.synthetic_camera = true;
                SetError("No device found, using synthetic mode");
            }
        } catch (...) {
            SetError("Device discovery failed, fallback to synthetic");
        }
    }
    // 继续使用 synthetic
    return true;
}
```

### 5.3 最后错误查询

```cpp
std::string PercipioCamera::LastError() const {
    return impl_->LastError();
}
```

**用途**:
- gRPC GetYoloResult 可在 response.status 中返回错误
- C# 客户端记录日志
- 便于故障诊断

## 6. 性能考虑

### 6.1 Synthetic 模式

| 指标 | 值 |
|-----|-----|
| CPU 占用 | ~5% per core |
| 内存 | ~50MB |
| 帧率 | 30 fps (稳定) |
| 延迟 | <5ms |
| 高优先级 | 否 |

### 6.2 SDK 模式

| 指标 | 估计值 |
|-----|--------|
| CPU 占用 | 10-15% per core |
| 内存 | 100-150MB |
| 帧率 | 30 fps (设备限制) |
| 延迟 | 10-30ms (硬件相关) |
| 高优先级 | 需要手动设置 |

### 6.3 优化建议

1. **避免帧拷贝**:
   - 当前使用 `std::vector::assign()` 拷贝数据
   - 可改进为引用计数或共享缓冲区

2. **线程优先级**:
   - Worker 线程应设置为高优先级
   - `SetThreadPriority(GetCurrentThread(), THREAD_PRIORITY_ABOVE_NORMAL)`

3. **内存预分配**:
   - 预分配最大分辨率的帧缓冲
   - 避免运行时 malloc/free

void OnFrameSetCallback(const FrameSet& fs) {

## 8. 测试策略

### 8.1 单元测试

**不需要实际设备**:
```cpp
TEST(PercipioCamera, SyntheticMode) {
    ServiceConfig cfg;
    cfg.synthetic_camera = true;
    
    PercipioCamera cam(cfg);
    EXPECT_TRUE(cam.Init());
    EXPECT_TRUE(cam.Connect());
    
    FrameSnapshot frame;
    EXPECT_TRUE(cam.Grab(frame, 1000));
    EXPECT_GT(frame.ticks, 0);
    EXPECT_EQ(frame.color.width, cfg.frame_width);
}
```

### 8.2 集成测试

**需要真实设备和 C# 客户端**:
```cpp
TEST(PercipioCamera, RealDeviceIntegration) {
    ServiceConfig cfg;
    cfg.synthetic_camera = false;
    cfg.camera_ip = "192.168.1.20";
    
    PercipioCamera cam(cfg);
    EXPECT_TRUE(cam.Init());
    EXPECT_TRUE(cam.Connect());
    EXPECT_TRUE(cam.Start());
    
    for (int i = 0; i < 30; i++) {  // 1 second at 30fps
        FrameSnapshot frame;
        EXPECT_TRUE(cam.Grab(frame, 100));
    }
    
    EXPECT_TRUE(cam.Stop());
}
```

### 8.3 性能基准

```cpp
BENCHMARK(FrameGrab) {
    PercipioCamera cam(config);
    cam.Start();
    
    for (int i = 0; i < 1000; i++) {
        FrameSnapshot frame;
        cam.Grab(frame, 100);  // 应 < 5ms
    }
    
    cam.Stop();
}
```
