### 5️⃣ WorkerLoop() - 改进的线程处理

```cpp
void WorkerLoop() {
    while (!stop_requested_) {
#ifdef LBGM461_ENABLE_PERCIPIO_SDK
        if (config_.synthetic_camera) {
#endif
            // Synthetic 模式：生成测试帧
            const auto ticks = NowTicks();
            FrameSnapshot frame = GenerateSyntheticFrame(ticks);
            {
                std::lock_guard<std::mutex> lock(mutex_);
                latest_frame_ = std::move(frame);
                latest_ticks_ = ticks;
            }
            cv_.notify_all();
            std::this_thread::sleep_for(...);
#ifdef LBGM461_ENABLE_PERCIPIO_SDK
        } else {
            // SDK 模式：等待回调更新
            std::this_thread::sleep_for(std::chrono::milliseconds(10));
        }
#endif
    }
}
```

**位置**: PercipioCamera.cpp, Impl::WorkerLoop()  
**功能**: 两种模式的自适应处理  
**Synthetic**: 生成虚拟帧，保证测试可用性  
**SDK**: 被动接收回调，最小化 CPU 占用

### 6️⃣ OnFrameSetCallback() - 帧转换

```cpp
void OnFrameSetCallback(const FrameSet& frameset) {
    std::int64_t ticks = NowTicks();
    
    Image depth_img = frameset.GetImage(SensorType::Depth);
    Image color_img = frameset.GetImage(SensorType::Texture);
    
    FrameSnapshot frame;
    frame.ip = config_.camera_ip;
    frame.ticks = ticks;
    frame.depth_scale = config_.depth_scale;
    
    if (depth_img.IsValid()) {
        frame.depth.width = depth_img.width();
        frame.depth.height = depth_img.height();
        frame.depth.mat_type = 2;  // CV_16UC1
        frame.depth.data.assign(depth_img.data(), 
                                depth_img.data() + depth_img.data_size());
    }
    
    if (color_img.IsValid()) {
        frame.color.width = color_img.width();
        frame.color.height = color_img.height();
        frame.color.mat_type = 16;  // CV_8UC3
        frame.color.data.assign(color_img.data(),
                                color_img.data() + color_img.data_size());
    }
    
    {
        std::lock_guard<std::mutex> lock(mutex_);
        latest_frame_ = std::move(frame);
        latest_ticks_ = ticks;
    }
    cv_.notify_all();
}
```

**位置**: PercipioCamera.cpp, Impl::OnFrameSetCallback()  
**功能**: 从 SDK FrameSet 转换到内部 FrameSnapshot  
**安全**: 线程安全的数据交换  
**格式**: 保留 depth/color 分离，兼容 C# 读取

## 🎯 关键特性

### ✅ 向后兼容性
- **CameraService** 无需改动：公有接口完全相同
- **GrpcServer** 无需改动：GetYoloResult 流程不变
- **C# 客户端** 无需改动：gRPC 协议 100% 兼容

### ✅ Fallback 机制
- **无 SDK 环境**: 自动降级到 synthetic frames
- **设备离线**: 自动切换到 synthetic 进行测试
- **编译降级**: 无 protobuf/gRPC 时仍能编译

### ✅ 线程安全
- 所有帧数据通过 mutex + condition_variable 交换
- 回调在 SDK 线程中执行，不阻塞主线程
- 单调递增的 ticks，防止帧重复

### ✅ 可配置性
- CLI 参数支持：`--camera-sn`, `--camera-ip`, `--synthetic`
- CMake 选项：`LBGM461_ENABLE_PERCIPIO_SDK`, `LBGM461_PERCIPIO_SDK_ROOT`
- 内部配置：ServiceConfig 结构体

## 📞 技术支持

### 常见问题

**Q: 为什么需要 Pimpl 模式?**  
A: 隐藏 Percipio SDK 依赖，使项目在无 SDK 时也能构建和运行。

**Q: Synthetic 模式和真实 SDK 模式有什么区别?**  
A: Synthetic 生成虚拟帧用于测试，SDK 模式读取真实摄像头。两者通过 `config_.synthetic_camera` 标志控制。

**Q: 如何在 Windows 上测试?**  
A: 使用 `--synthetic` 参数运行，无需摄像头连接。

**Q: 共享内存格式是否兼容旧 C# 程序?**  
A: 是的，100% 兼容。数据格式、protobuf 序列化、ticks 定义都保持不变。
