## TODO 3：实现 gRPC 服务入口

**目标：** 对外提供与现有主程序兼容的 ImageService 接口。

**接口定义：**
- 输入：ProtoYoloRequest
- 输出：ProtoYoloResponse
- 谁调用：旧主程序通过 127.0.0.1:5111 连接
- 副作用：可能触发相机抓帧和共享内存写入

**实现逻辑：**

1. 启动本地 gRPC 服务并监听固定端口
2. 在 GetYoloResult 中获取最新帧快照
3. 调用共享内存写入层生成文件
4. 返回 successful、path 和 ticks
5. InitModels 先做兼容占位，后续再接模型加载

**边界处理：**
- 请求为空：返回失败状态
- 无可用帧：返回失败状态并记录日志
- 共享内存写失败：返回失败状态

**依赖：** 需要先完成 TODO 1、TODO 2

## TODO 4：封装 Percipio 相机适配层

**目标：** 把 Percipio SDK 相关调用封装为独立相机模块。

**接口定义：**
- 输入：相机配置、采集超时、连接信息
- 输出：最新图像帧与内参
- 谁调用：服务入口的抓帧流程
- 副作用：占用相机设备、维护连接状态

**实现逻辑：**

1. 在初始化阶段完成 SDK 载入与设备发现
2. 连接指定相机并获取内参信息
3. 启动后台采集线程，持续更新最新帧缓存
4. 提供单帧抓取接口供 gRPC 请求线程读取
5. 在连接异常时触发重连

**边界处理：**
- SDK 不可用：返回初始化失败
- 相机断开：进入重连流程
- 取帧超时：返回失败状态

## TODO 5：实现共享内存写入

**目标：** 将最新帧按现有 C# 协议写入 /dev/shm。

**接口定义：**
- 输入：一帧图像快照与路径后缀
- 输出：写入后的共享文件路径
- 谁调用：gRPC 请求处理逻辑
- 副作用：创建或覆盖共享内存文件

**实现逻辑：**

1. 按路径后缀拼出共享文件路径
2. 将图像数据与内参序列化为二进制
3. 按“长度 + payload”格式写入文件
4. 写入失败时回收资源并返回错误

**边界处理：**
- 文件不存在：自动创建
- 写入中断：保证句柄正确关闭
- 数据为空：拒绝写入

**依赖：** 需要先完成 TODO 2
