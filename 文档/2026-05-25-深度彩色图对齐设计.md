# 深度图与彩色图坐标对齐

## 概述

解决深度图（640×400）与彩色图（640×480）分辨率/坐标系不一致的问题。通过 SDK 的 `TYMapDepthImageToColorCoordinate()` 将深度图映射到彩色图坐标系，再对两者做中心裁剪统一为 640×400。彩色图保留原始画质不被映射算法破坏，上位机可直接用同一坐标 (x, y) 同时读取颜色和深度值。允许部分像素深度为 0（无有效测量）。

## 相关文件

- `src/camera/PercipioCamera.cpp` — 相机连接、帧采集与处理
- `src/common/FrameTypes.h` — 帧数据结构定义
- `include/TYCoordinateMapper.h` — SDK 坐标映射 API
- `include/TYDefs.h` — `TY_CAMERA_CALIB_INFO` 结构定义

## 核心逻辑

### 一、连接阶段补充标定数据

`PercipioCamera::Impl::Connect()` 中，启用深度和彩色组件之后：

1. 用 `TYGetStruct(TY_COMPONENT_DEPTH_CAM, TY_STRUCT_CAM_CALIB_DATA)` 获取深度相机完整标定数据，保存为 `depthCalib_`。
2. 用 `TYGetStruct(TY_COMPONENT_RGB_CAM, TY_STRUCT_CAM_CALIB_DATA)` 获取彩色相机完整标定数据，保存为 `colorCalib_`。
3. 日志输出双相机标定信息（分辨率、焦距），便于调试确认。

### 二、帧处理阶段执行映射

`PercipioCamera::Impl::ProcessFrame()` 中，提取完原始深度图和彩色图之后：

1. 确认深度图和彩色图数据均非空、且彩色标定数据可用。
2. 将原始深度图（640×400）通过 `TYMapDepthImageToColorCoordinate()` 映射到彩色图坐标系（640×480），得到与彩色图同尺寸的对齐深度图。
3. 取两者较小尺寸（640×400）为输出目标，对彩色图和对齐后深度图分别做中心裁剪。
4. 重新计算裁剪后的彩色坐标系内参（`BuildColorAlignedIntrinsics()`），确保上位机 3D 反投影正确。
5. 首帧输出有效深度比例日志。

### 三、输出变化

映射完成后，`FrameSnapshot` 中的数据变为：

- `color`：640×400，BGR，原始画质中心裁剪
- `depth`：640×400，DEPTH16，对齐到彩色图坐标系（部分像素深度为 0 属正常）
- `intrinsics`：裁剪后的彩色坐标系内参（用于上位机做 3D 反投影）

上位机无需做任何坐标转换，YOLO 检测到目标在 (x, y) 时，直接去 depth[y][x] 读深度即可。

## 关键方法

| 方法 | 职责 |
|------|------|
| `PercipioCamera::Impl::Connect()` | 获取并保存深度+彩色两组完整标定数据 |
| `PercipioCamera::Impl::ProcessFrame()` | 帧到达后执行深度→彩色坐标系映射 + 中心裁剪 |
| `TYMapDepthImageToColorCoordinate()` | SDK 函数，将深度图投影到彩色相机视角 |
| `CropBgrImage()` | 对 BGR 彩色图做中心裁剪 |
| `CropDepthImage()` | 对 uint16 深度图做中心裁剪 |
| `BuildColorAlignedIntrinsics()` | 根据裁剪偏移重算输出内参 |
| `CalculateValidDepthPercent()` | 统计有效深度像素比例 |

## 注意事项

1. 深度值为 0 的区域（超出测量范围或遮挡），对齐后深度图对应位置为 0，彩色图不受影响。实测有效深度约 80%。
2. 物体边缘可能有少量深度缺失（深度相机和彩色相机有物理间距导致遮挡），对抓取定位无影响。
3. 映射在 CPU 上执行，640×400 级别约 1-3ms，不影响整体帧率。
4. 彩色图保持原始质量，不再经过坐标映射重采样，避免噪点和伪影。

| `PercipioCamera::Impl::Connect()` | 获取并保存深度+彩色两组完整标定数据 |
| `PercipioCamera::Impl::ProcessFrame()` | 帧到达后执行 RGB→深度坐标系映射 |
| `TYMapRGBImageToDepthCoordinate()` | SDK 函数，利用双目标定参数将彩色图投影到深度图视角 |

## 注意事项

1. 深度值为 0 的区域（超出测量范围），对齐后的彩色图对应位置为黑色（全零），这是正常行为。
2. 物体边缘可能有 1-2 像素的遮挡黑边（深度相机和彩色相机有物理间距），对抓取定位无影响。
3. 映射在 CPU 上执行，640×400 级别约 1-3ms，不影响整体帧率。
