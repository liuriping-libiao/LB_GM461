## 2. 技术实现细节

### 2.1 SDK 初始化流程

```cpp
// Init()
CameraUtils::Init(true);  // Direct mode (not RPC)

// Connect()
auto devicelist = CameraUtils::DiscoverCameras();
camera_ = CameraFactory::GetCamera(sn, ip);
camera_.Connect();

// Start()
camera_.SetSensorEnabled(SensorType::Depth, true);
camera_.SetSensorEnabled(SensorType::Texture, true);
camera_.SetMapDepthToTextureEnabled(true);
camera_.RegisterFrameSetCallback([this](const FrameSet& fs) {
    OnFrameSetCallback(fs);
});
camera_.StartCapture();
```

### 2.2 帧回调处理

```cpp
void OnFrameSetCallback(const FrameSet& frameset) {
    Image depth_img = frameset.GetImage(SensorType::Depth);
    Image color_img = frameset.GetImage(SensorType::Texture);
    
    FrameSnapshot frame;
    frame.ip = config_.camera_ip;
    frame.ticks = NowTicks();
    frame.depth_scale = config_.depth_scale;
    
    // Copy depth data
    frame.depth.width = depth_img.width();
    frame.depth.height = depth_img.height();
    frame.depth.mat_type = 2;  // CV_16UC1
    frame.depth.data.assign(depth_img.data(), 
                            depth_img.data() + depth_img.data_size());
    
    // Copy color data
    frame.color.width = color_img.width();
    frame.color.height = color_img.height();
    frame.color.mat_type = 16;  // CV_8UC3
    frame.color.data.assign(color_img.data(),
                            color_img.data() + color_img.data_size());
    
    // Update shared state
    {
        std::lock_guard<std::mutex> lock(mutex_);
        latest_frame_ = std::move(frame);
        latest_ticks_ = ticks;
    }
    cv_.notify_all();
}
```

### 2.3 向后兼容性

- **Synthetic 模式保留**: 当 `config_.synthetic_camera = true` 时，仍使用内部生成的测试帧
- **无 SDK 构建**: 当 `LBGM461_ENABLE_PERCIPIO_SDK = OFF` 时，自动降级到 synthetic
- **错误处理**: 所有 SDK 调用都检查返回状态，失败时设置错误信息并回退

- Visual Studio 2022 with CMake support
- VcameraSDK-26.1.5 已复制到 `include/vcamera/`

## 5. 故障排除指南

### 问题 1: 编译错误 "undefined reference to vcamera::..."

**原因**: 链接阶段找不到 SDK 库  
**解决方案**:
- 这是正常的，因为 SDK .so 库仅在 Linux 上可用
- Windows 上可以编译但无法链接实际 SDK 库
- 使用 `--synthetic` 运行以跳过 SDK 依赖

### 问题 2: 运行时错误 "No Percipio camera device found"

**原因**: 设备未连接或 SN/IP 不匹配  
**解决方案**:
```bash
# 查看可用设备
./camera_service --list-devices

# 或运行 SDK 提供的 ListDevices 示例
# $VcameraSDK/cpp/example/ListDevices.cpp
```

### 问题 3: 共享内存文件为空或损坏

**原因**: 帧数据未正确转换或序列化  
**解决方案**:
- 检查 OnFrameSetCallback 中的 data_size() 是否为 0
- 验证 mat_type 和 width/height 设置是否正确
- 查看 ProtobufWire::EncodeShareData 的输出大小
